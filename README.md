# Aqib Malik - Portfolio
React + Vite. Dark red theme with animated hero, particles, custom cursor and floating dock.

- Live preview (local server): `npm install && npm run dev`  -> http://localhost:5173
- Production build: `npm run build` (output in `dist/`)
- Publish to GitHub + Pages: `bash deploy.sh portfolio`, then Settings > Pages > Source: GitHub Actions
- Netlify/Vercel: build command `npm run build`, publish directory `dist`
- Your photo lives in `src/assets/portrait.jpg`; project links are in `src/App.jsx`.
